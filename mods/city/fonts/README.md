OpenCity Pixel Regular/Bold is Pixel Operator with added glyphs for the UI: `¤ § ª º ¯ ¹ ² ³ ¼ ½ ¾`, soft hyphen,
`← ↑ → ↓ ▲ ▼ ▶ ◀ ✓ ✗ − ≤ ≥ ∞ ● ○ ★ ♥`. The 8/10/12 px faces are subsets (Latin-1, Latin Extended-A, punctuation,
currency, arrows, maths, shapes, symbols) renamed "OpenCity Pixel 8/10/12"; the upstream licenses declare no reserved font names.

All outlines lie on whole pixels: the engine renders each face at its grid size without antialiasing and enlarges it by
whole device pixels (`FontData.PixelFaces` in `mod.yaml`). Having several design sizes (cap heights 6, 7 and 9 px, plus
their multiples) lets every font stay within about 15% of its intended size at any UI scale.

Generated by dev-only tools (need `pip install fonttools`), outputs committed:
`mods/city/tools/genfont.py` (OpenCity Pixel Regular/Bold) and `mods/city/tools/genfontsubset.py` (8/10/12 px faces).
