# OpenCity fonts

The game UI uses antialiased FreeSans and FreeSans Bold from `mods/common`, rasterized at the
current display/UI scale. The pixel faces below remain available as source assets but are no
longer selected by `mods/city/mod.yaml`.

| File | Grid / cap height | Origin | License |
| --- | --- | --- | --- |
| `OpenCityPixel-Regular.ttf`, `OpenCityPixel-Bold.ttf` | 16 px / 9 px | Derived from Pixel Operator by Jayvee Enaguas (HarvettFox96), https://github.com/bauripalash/ttf-pixeloperator-fork (commit `496045526d00b66e37ca11762c446b7423145822`) | CC0 1.0, see `LICENSE-PixelOperator.txt` |
| `OpenCityPixel8.ttf` | 8 px / 6 px | Latin subset of Fusion Pixel Font 8px proportional by TakWolf, https://github.com/TakWolf/fusion-pixel-font (release 2026.09.25) | SIL OFL 1.1, see `OFL-FusionPixel.txt` and `LICENSES-FusionPixel/` |
| `OpenCityPixel10.ttf` | 10 px / 7 px | Latin subset of Ark Pixel Font 10px proportional by TakWolf, https://github.com/TakWolf/ark-pixel-font (release 2026.09.25) | SIL OFL 1.1, see `OFL-ArkPixel.txt` |
| `OpenCityPixel12.ttf` | 12 px / 9 px | Latin subset of Ark Pixel Font 12px proportional by TakWolf (same release) | SIL OFL 1.1, see `OFL-ArkPixel.txt` |

OpenCity Pixel Regular/Bold is Pixel Operator with added glyphs for the UI: `¤ § ª º ¯ ¹ ² ³ ¼ ½ ¾`, soft hyphen,
`← ↑ → ↓ ▲ ▼ ▶ ◀ ✓ ✗ − ≤ ≥ ∞ ● ○ ★ ♥`. The 8/10/12 px faces are subsets (Latin-1, Latin Extended-A, punctuation,
currency, arrows, maths, shapes, symbols) renamed "OpenCity Pixel 8/10/12"; the upstream licenses declare no reserved font names.

These legacy outlines lie on whole pixels. The engine's optional `FontData.PixelFaces` path renders
each face at its grid size without antialiasing and enlarges it by whole device pixels. It is
unsuitable for the city's dense text at fractional display scales, so the active UI uses outline fonts.

Generated by dev-only tools (need `pip install fonttools`), outputs committed:
`mods/city/tools/genfont.py` (OpenCity Pixel Regular/Bold) and `mods/city/tools/genfontsubset.py` (8/10/12 px faces).
